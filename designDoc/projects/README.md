# Projects

本目录保存本仓库的项目资料。每个项目使用一个 `NNN_slug/` 文件夹，入口是其中的 `PROJECT.md`，也就是 Project Outline：它说明项目目标、范围、owner、当前进度、下一步，以及本项目资料分别在哪里。

目录与序号、保存范围、既有项目归位的规则由 [Project Documentation](../the_project_documentation.md) 第 8.2 节规定，本页不重复。新建项目前先查看本目录的现有文件夹及其 `PROJECT.md`，同一项目在原文件夹续作；确需新建时，序号取现有最大序号加一。

项目列表就是本目录下的文件夹，本页不另列清单，避免两处维护。
