# 26 Trades For 2026 Thesis-First Routing Plan

This note is a non-canonical planning document for how `manual_report_20260331T080242Z_26-trades-for-2026_988002b409` should be absorbed into the local research system.

It is not a claim that every trade idea in the source report deserves a new top-level theme.

The purpose of this note is to make one planning judgment explicit:

- the report is rich enough to generate many useful local objects
- most of those objects should land as `thesis` first
- only a small subset should later be promoted into `theme candidate` or folded into existing `approved theme` objects

## Why This Note Exists

`26 Trades for 2026` is closer to an `idea bundle` or `theme mine` than to a clean one-theme package.

If the system promotes each section directly into a top-level theme, the result will likely be:

- too many thin themes
- weak routing boundaries
- overlap between `theme`, `thesis`, `snapshot`, and `single-stock` layers
- poor future maintainability when later materials arrive

The more stable path is:

1. mine durable judgments from the source
2. store them as `thesis` where possible
3. fold them into existing themes when a clear home already exists
4. promote only the small minority that become repeated, reusable, cross-material industry mainlines

## Current Working Judgment

The correct default for this source is `thesis first`, not `theme first`.

That means:

- `snapshot` remains useful as a first-pass decomposition layer
- `thesis` is the primary durable destination for most sections
- `theme` should be reserved for recurring industry or cross-asset routing layers

In practical terms, this report should be treated as a backlog feeder for:

- `thesis_notes`
- existing theme evidence surfaces
- a limited number of future `theme candidate` objects

## Routing Principle

Use this decision order for each section of the report:

1. Does the section clearly belong inside an existing approved or candidate theme with strong boundary fit
2. If not, is the section still durable enough to become a standalone `thesis`
3. If not, should it remain only as `snapshot`, `single-stock`, or `trade framing`

Do not reverse that order.

Do not ask first whether a section is interesting enough to deserve a theme.

Ask first whether it is broad, repeatable, and routing-relevant enough to survive as one.

## Guardrails

- Do not let the richness of the source report force top-level theme inflation.
- Do not create a new theme just because a section title sounds thematic.
- Do not confuse `industry interest` with `routing authority`.
- Do not collapse single-name trade expressions into fake industry themes.
- Prefer a smaller number of stronger themes and a richer `thesis` layer underneath.

## Working Conclusion

`26 Trades for 2026` should be treated as a high-yield thesis backlog and candidate-theme feeder.

The correct near-term plan is:

- thesis first
- selective fold-in to existing themes
- delayed and evidence-based promotion for only a few future candidates

That path preserves useful detail from the source while keeping the local theme system legible.
