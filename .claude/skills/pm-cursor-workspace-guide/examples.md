# Example Requests

Use requests like these when working in Cursor as a PM.

## 1. Set up the workspace

`Create a common PM workspace for this project. I want PRD, BRD, personas, rules, handoffs, and reviews in one place.`

## 2. Turn messy notes into a PRD

`Turn these rough notes into a clean PRD with goals, scope, edge cases, and acceptance criteria.`

## 3. Create role-specific handoffs

`Based on the PRD and personas, write three briefs: one for Data Scientist, one for Design, and one for Engineering.`

## 4. Keep rules visible

`Extract the non-negotiable rules from this BRD and turn them into a review checklist.`

## 5. Review specialist output

`Compare this design draft against the PRD and acceptance criteria. Tell me what matches, what is missing, and what needs clarification.`

## 6. Prepare an MVP

`Convert this product plan into an MVP scope and a live demo checklist.`

## 7. Track iteration

`Summarize what changed between v1 and v2 of this proposal and update the decision log.`

## 8. Keep role boundaries clear

`Help me review the engineer's proposal without rewriting their technical solution for them.`
